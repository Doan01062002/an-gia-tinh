# An Gia Tịnh — Bàn Thờ Hiện Đại & Không Gian Thờ Chuẩn Phong Thủy

Website bán hàng và cẩm nang kiến trúc phòng thờ chuẩn **Thước Lỗ Ban 38.8cm** cho thương hiệu **An Gia Tịnh**.

## 🌟 Bản Sắc & Cam Kết Cốt Lõi (USP)
- **100% Gỗ Lõi Tự Nhiên Không Rác (Đền bù 200%)**: Gỗ Sồi Mỹ, Gỗ Gõ Đỏ Pachy, Gỗ Gụ Lào tuyển chọn lõi già, sấy lò nhiệt $10-12\%$.
- **Thước Lỗ Ban 38.8cm Âm Phần Chuẩn Cung Đỏ**: Mọi kích thước ban thờ đều được cắt trúng các cung Đăng Khoa, Hỷ Sự, Thêm Phúc, Tiến Bảo, Lục Hợp.
- **Duyệt Video Mộc Thô 15s**: Khách hàng được kiểm tra cận cảnh thớ vân gỗ mộc trước khi xưởng phun sơn Inchem hoàn thiện.
- **Đóng Gói White-Label & Giao COD Toàn Quốc**: Kiểm tra hàng ưng ý mới thanh toán.
- **Bảo Hành 10 - 20 Năm**: Chống mối mọt, cong vênh, nứt nẻ.

---

## 🚀 Kiến Trúc Công Nghệ
- **Framework**: [Astro 5](https://astro.build) — Tối ưu hóa Static Site Generation (SSG) với tốc độ tải trang 0.2s, Zero-JavaScript mặc định để đạt điểm Core Web Vitals 100/100 tuyệt đối.
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com) — Bảng màu gỗ ấm áp, sang trọng (Nâu Óc Chó `#2C1A11`, Vàng Hoàng Kim `#D4AF37`, Kem Ngà `#FAF7F2`).
- **Interactive Islands**: React component cho công cụ tra cứu **Thước Lỗ Ban 38.8cm** và bộ mồi câu tâm linh (Spiritual Hooks).
- **SEO & Structured Data**: Tích hợp JSON-LD Schema (`HomeGoodsStore`, `Product`, `Article`, `FAQPage`, `BreadcrumbList`), OpenGraph, Twitter Cards và tự động tạo `sitemap-index.xml`.
- **Hosting**: [Vercel](https://vercel.com) — Edge Network CDN toàn cầu, chi phí 0đ.
- **CI/CD**: GitHub Actions tự động kiểm thử và verify build production trên nhánh `main`.

## 🛠️ Lệnh Phát Triển & Build
```bash
# Cài đặt thư viện
npm install

# Chạy môi trường dev local (localhost:4321)
npm run dev

# Build production HTML tĩnh
npm run build

# Xem trước bản build tĩnh
npm run preview
```
